## 1. 직접 해야 할 일 (순서대로, 15분쯤)

### ① SQL 두 개 실행 (Supabase → SQL Editor)
여러 번 실행해도 안전하다. **아래 순서대로**, 파일 내용을 그대로 붙여 넣고 Run.

1. `supabase/migrations/20261107000000_hardening.sql`
   - 색인(사람이 늘어도 표 전체를 훑지 않게), 한 경기에 논거 하나, 지운 사주 기능의 개인 정보 칸(생일 등) 지우기, 브라우저 공개 키 권한 거두기.
2. `supabase/migrations/20261108000000_names_notices.sql`
   - **이걸 실행하기 전에는 닉네임 바꾸기가 "지금은 닉네임을 바꿀 수 없어요"로 막혀 있다.** 운영자 코인 선물·방문 알림도 저장되지 않는다(실시간 방문 알림만 뜬다).

확인: SQL Editor에서 `select name from schema_migrations order by name desc limit 3;` → 두 파일 이름이 보이면 끝.

### ② Vercel `CRON_SECRET` 넣기
매일 21:01(한국 시각) 예약 작업이 돈다. 이 값이 없으면 예약 작업이 거절돼 **오래된 기록 정리(하루 열매·낚시, 방문, 지난 대항전 점수 등)가 안 된다** (토론·대항전 집계는 첫 방문 때도 되므로 멈추지는 않는다).
1. Vercel → 프로젝트 → Settings → Environment Variables → Add
2. 이름 `CRON_SECRET`, 값은 아무도 모를 긴 무작위 글자(비밀번호 관리자에서 32자 이상 만들기), 환경 **Production**
3. Deployments → 맨 위 배포 → Redeploy (환경변수는 다시 배포해야 들어간다)
- 값을 나에게 알려 줄 필요는 없다. Vercel이 예약 작업을 부를 때 알아서 붙인다.

### ③ Supabase 비밀번호 최소 길이 8
Supabase → Authentication → Sign In / Providers → Email → **Minimum password length = 8** → Save.
(메뉴 이름이 다르면 Authentication 안에서 "password"를 찾는다.) 화면은 이미 8자를 요구하지만 서버 기본값이 6이라 맞춘다.

## 2. 휴대폰 버벅임: 원인과 해결

코드를 훑어 원인을 찾았다 (기기에서 재 보지는 않았다). 큰 것부터.

| # | 원인 | 왜 무거운가 | 고칠 방법 |
|---|---|---|---|
| 1 | **마을 전체를 매 장면 두 번 그린다** | 나무·풀·꽃·소품 수천 개(약 20만 삼각형)와 집 128채, 땅이 화면 밖이어도 빠지지 않는다. 그림자도 전부 드리우고, 해가 나를 따라와 그림자 지도를 매 장면 새로 그린다 | 소품을 구역별로 나눠 화면 밖은 안 그리기, 풀·꽃·작은 덤불은 그림자 끄기, 그림자는 내가 한 칸쯤 움직였을 때만 다시 그리기 |
| 2 | **움직이는 캐릭터가 많다** | 다른 사람 최대 40명 + 펫, 한 명이 약 1만 삼각형·뼈 66개. 멀리 있거나 화면 밖이어도 매 장면 동작을 계산하고 그림자를 드리운다 | 휴대폰은 12~15명까지만, 먼 캐릭터는 동작을 가끔만 계산·그림자 끄기 |
| 3 | **픽셀이 많고 비싸다** | 안티에일리어싱이 늘 켜져 있고, 그림자를 한 픽셀에 5번 읽는다(바다까지). 방은 해상도를 2배까지 쓴다 | 휴대폰은 해상도 1~1.25배, 가벼운 모드에서 안티에일리어싱·바다 그림자 끄기 |
| 4 | **창을 열어도 뒤에서 계속 그린다** | 가방·도감·캐릭터 창이 화면을 다 덮어도 마을은 계속 그리고, 캐릭터 창은 3D 화면을 하나 더 띄운다 | 창이 열려 있으면 뒤 장면 멈추기 |
| 5 | 방 그림자를 매 장면 다시 그린다 | 방 해는 움직이지 않는다 | 가구가 바뀔 때만 다시 그리기 |
| 6 | 처음 보는 모델이 나타날 때 잠깐 멈춤 | 주민·여자 캐릭터·강아지가 처음 나올 때 받기·풀기·동작 만들기를 한 번에 한다 | 첫 화면 뒤 한가할 때 미리 준비 |
| 7 | 이름표 하나에 그림 하나 | 집 이름표 128개 + 주민 이름표가 저마다 큰 그림 | 휴대폰은 이름표 그림을 작게 |

받는 파일 크기는 문제가 아니다 (처음에 3MB쯤, 음악은 틀 때만 받는다).

**제안**: 휴대폰·느린 기기를 알아서 알아보는 **"가벼운 모드"**를 넣는다 (1·2·3·4번을 한 번에). 반나절~하루 작업. 그 전에 알려 주면 좋은 것:
- 버벅이는 폰 기종 (아이폰 몇, 갤럭시 몇)
- 어디서 가장 버벅이는지 (마을 광장 / 내 방 / 클럽 / 창을 열 때)
- 계속 느린지, 처음 몇 초만 멈추는지
